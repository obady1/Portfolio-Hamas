# Hamas-Portfolio
**Designing a front-end website to display a brief overview of the Hamas movement**
<video controls src="assets/vid/HamasVid.mp4" title="show Hamas Portfolio"></video>
## Site structure (sections)
### 1. Header
It has a top navigation bar that allows quick navigation between page sections.
It has a Login button, which suggests there may be a member or administration control panel.
### 2. Home section
The headline displays: "Islamic Resistance Movement HAMAS".
It contains the official logo of the movement and social media images (Telegram and Facebook).
### 3. About section
It provides a brief introductory text about the movement, its origins, its victory in the 2006 legislative elections, and its control of Gaza.
Illustrates the differing international views towards the movement.
### 4.“Work” section
The “Work” section was used in an unconventional way to display:
Percentage of control over the Gaza Strip.
Percentage of combatants.
Military industrialization.
Global support.
Displays photos from events and marches.
### 5. Leaders and Factions Gallery (Gallery)
Leaders Section: Displays a photo grid of prominent leaders (historical and later).
Influential leaders section: includes names such as Sheikh Ahmed Yassin and Abdul Aziz Al-Rantisi.
Armed Factions Section: Displays the logos of the various military blocs.
### 6. Contact Department
An interactive form requesting:
Full name.
Email and phone number.
the address.
Optional message.
## Technologies used
* HTML5: for the structural structure of the page.
* CSS3: For external formatting file (assets/css/styles.css) to control the design and colors.
* Box Icons: An icon library for social icons and menus.
* Scroll Reveal: A JavaScript library for creating animation effects when scrolling down the page.
* JavaScript: For the main control file (assets/js/main.js) to interact with the responsive menu and contact form.
